# MoonQuest Unity 6 Development Branch

## Overview

This directory contains the MoonQuest VR streaming client project migrated to Unity 6. This branch was created to test whether critical bugs present in the main development branch would be resolved in a newer Unity version.

## Unity Version

**Unity 6.2.14f1** (6000.2.14f1)

## Branch Purpose

I sought to upgrade the Unity version in an effort to see if the bugs that I was dealing with in the version that is considered my main development would be fixed. It does not seem so. However, I decided to push it and have it saved anyway, just in case the bug gets fixed. Chances are, if it gets fixed, then it's going to be something that's probably done in the most recent release, which this version of Unity 6 is currently.

## Changes from Main Development Branch

There are some things that have changed from the development branch in order to get it up to date. I will be working in both branches—the development branch and the Unity 6 development branch—just to see if I can spot any differences.

## Development Status

**Currently in Beta/Alpha Stage**

Once I've got an optimized version that I'm comfortable enough with, I'll decide between these two branches on which one I decide to make my first release. Until then, these remain in the beta stage (or alpha development stage), as I'm adding features and most importantly focusing on optimization of:

- **Video Quality**
- **Sound Quality**
- **Overall Quality of Life**

Once optimization is solid, I can really focus on adding extra features.

## Repository Structure

This branch is maintained separately from the main development branch. Both branches will be actively developed until a decision is made on which version will be used for the first release.
